# PCBridge 1.7.0 — браузер Playwright

Это отдельный Chromium, созданный мостом. Он не подключается к существующим браузерам и вкладкам пользователя. Контекст, cookies, страницы и загрузки живут в отдельном worker; перезапуск worker создаёт новую сессию. Постоянный профиль и подключение к Firefox/Edge пользователя не реализованы.

Модуль требует `enable_browser=true` и `enable_internet=true`. Действия в формах также требуют `enable_input=true`; все записи и навигация запрещены в read-only. Настройка добавлена в START/SETTINGS и панель управления. После изменения модулей нужен перезапуск.

Зависимости: `playwright>=1.64,<2`; пакет и Chromium уже установлены в этой копии. Установщик повторно использует скачанный Chromium. Это управляемый браузер Playwright; системный браузер по умолчанию не меняется.

## Инструменты

| Инструмент | Назначение |
|---|---|
| `browser_open(url="about:blank", headless=False)` | Создать собственную вкладку и получить первый снимок |
| `browser_tabs()` | Список принадлежащих мосту вкладок |
| `browser_navigate(page_id, url)` | Перейти по адресу в своей вкладке |
| `browser_snapshot(page_id, max_chars=20000, max_depth=12)` | AI accessibility snapshot, включая доступный контент iframe, с refs |
| `browser_find(page_id, snapshot_id, text, role)` | Получить только подходящие строки/refs существующего снимка |
| `browser_action(page_id, snapshot_id, ref, action, value, expect_text)` | click/fill/check/uncheck/select/press по ссылке |
| `browser_wait(page_id, text, present=True, timeout_seconds=10)` | Ожидать видимый текст основной страницы и получить новый снимок |
| `browser_diagnostics(page_id, limit=30)` | Ошибки консоли/страницы, запросов, HTTP-ошибки, IDs загрузок |
| `browser_save_download(download_id, save_as, overwrite=False)` | Сохранить загрузку на ПК с соблюдением workspace/full_disk и историей отмены |
| `browser_trace(action="start", save_as="", overwrite=False)` | По запросу начать/сохранить локальную трассу Playwright |
| `browser_close(page_id)` | Закрыть принадлежащую мосту вкладку |

Первый `browser_open` выбирает видимый или headless режим на время жизни worker. Ограничение — 10 одновременно открытых страниц. Перед новой сессией следует закрыть её или перезапустить мост; существующие пользовательские браузеры не затрагиваются.

## Работа с refs

Снимок возвращает YAML-подобное поле `aria` со ссылками `[ref=e2]`, а также `page_id` и `snapshot_id`. `browser_find` сокращает вывод; затем `browser_action` обращается к точному ref. Playwright проверяет готовность элемента и ожидает его перед вводом. Доступны ссылки на элементы iframe.

Новый снимок, действие, навигация или перезапуск делают старые refs недействительными. Срок — 120 секунд; смена документа проверяется дополнительно. После действия берите новый `snapshot.snapshot_id`. `verification.verified` проверяет значение, состояние флажка, выбранный вариант, появление popup или `expect_text`. Выполнение клика само по себе не доказывает достижение цели.

После таймаута/потери соединения действие могло выполниться: сначала наблюдать страницу. Код JavaScript/Python от агента не принимается. В диагностике видны автоматически отклонённые JS-диалоги; они отклоняются, чтобы не блокировать последующие вызовы.

Парольные значения маскируются в снимках; значения `value` и массивы `steps` скрыты в журнале вызовов. Ошибки ввода не возвращают значение поля в call log.

## Сеть, файлы и диагностика

Навигация разрешает HTTP(S) и about:blank. Встроенные логин/пароль в URL, file/data/javascript URL не разрешены. Запросы, редиректы и WebSocket-подключения проверяются по `allow_lan_urls`; по умолчанию частная сеть и localhost закрыты. Для разработки локального сайта это можно явно разрешить в настройках. Service Workers отключены для перехвата запросов. Это прикладная проверка адресов, а не отдельная сетевая песочница ОС.

Диагностика ограничена 200 событиями и по умолчанию возвращает последние 30; заголовки и тела запросов не выводятся, query/fragment и credentials удаляются из адресов диагностики. Консольные сообщения страницы могут содержать её данные.

Загрузки не передаются через контекст модели. Получите download_id из диагностики и явно сохраните через `browser_save_download`. Существующий путь требует `overwrite=true`; предыдущая версия сохраняется в истории. Пути проверяет сервер через существующую политику файлов.

Трасса включается только вызовом `browser_trace`; автоматической записи нет. Для остановки нужен `.zip` путь. Она содержит DOM/сетевые данные, остаётся на ПК и может содержать данные открытой страницы. Скриншоты по умолчанию выключены. ZIP можно открыть в Playwright Trace Viewer.
