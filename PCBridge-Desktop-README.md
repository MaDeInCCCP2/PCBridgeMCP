# PCBridge Desktop v0.1 — сборка для Windows x64

Нативное окно Rust + Slint полностью переносит пользовательскую панель управления PCBridge в отдельное Windows-приложение без открытия веб-панели в браузере. В окне доступны:

- **Обзор**: живая схема локального моста (`Этот компьютер -> Мост -> Туннель`), прямое переключение «Пауза» и «Только чтение» (с учётом фиксации в `config.json`), телеметрия и пошаговая проверка подключения (`POST /api/check`).
- **Работа**: вкладки со счётчиками («Задания», «Сеансы браузера», «Сеансы Windows»), поиск (`Ctrl+F`), фильтры статусов («Все», «Активные», «Ошибки») и прямые действия: остановка фоновых заданий, закрытие браузерных сеансов, пауза ввода и закрытие Windows-сеансов.
- **Активность**: вкладка «История файлов» со встроенным просмотром построчного `diff` и отменой изменений (`/api/undo`), а также вкладка «Живая лента» (`actions.log`) с фильтром и автообновлением.
- **Подключения**: домен и копирование полного адреса туннеля, показ/скрытие и копирование токена доступа, управление профилями `ngrok` (выбор активного, добавление, удаление), список и отзыв клиентов OAuth.
- **Расширения**: фильтры «Все / Включённые / Выключенные» и прямое включение/выключение навыков и плагинов.
- **Диагностика**: экспорт отчёта в `logs/pcbridge-diagnostics.json`, статус среды Computer Use, каталог инструментов MCP с тестовым повтором вызова (`/api/diagnostic-replay`), недавние вызовы и пошаговая проверка подключения.
- **Хранилище и Настройки**: инвентаризация с составной шкалой распределения диска, предпросмотр и безопасная очистка старых журналов, выбор темы («Как в Windows / Светлая / Тёмная»), поведение системного трея, уведомления Windows, автозапуск, консоль моста и переключатели модулей (с подтверждением для модулей с повышенными правами). Поддерживаются горячие клавиши `Ctrl+1..8`, `Ctrl+F` и `F5`.

## Запуск

В PowerShell из каталога, где находится `PCBridge-Desktop-x64.exe`:

```powershell
.\PCBridge-Desktop-x64.exe 'C:\Users\MaDeInCCCP\Documents\PCBridge — копия' --no-auto-cleanup
```

С флагом `--no-auto-cleanup` можно посмотреть интерфейс и размеры папки при отключённом мосте. Кнопка «Запустить» запускает установленный supervisor из существующей `.venv`. При работающем мосте главное действие проверяет подключение.

При наличии панели задач Windows закрытие окна сворачивает приложение в область уведомлений (трей) и продолжает фоновую автоочистку по расписанию; левый клик по значку в трее или повторный запуск с тем же каталогом вновь открывает окно, а пункт «Выход» в меню трея или в «Настройках» завершает приложение, оставляя уже запущенный мост работающим.

Для автоматической очистки запустите приложение без флага. В разделе «Хранилище» настраиваются включение фоновой проверки, срок хранения журналов (от 1 до 365 дней, по умолчанию 7) и частота проверки (6 ч, раз в сутки или раз в неделю). Срок хранения синхронизируется с `keep_logs_days` в `config.json` (если файл конфигурации присутствует), а параметры Desktop сохраняются в `logs/desktop-settings.json`. Кандидаты — журналы фоновых заданий старше выбранного срока при наличии достоверного результата задания. Занятые, изменившиеся и неоднозначные файлы сохраняются. Проверка по кнопке «Предпросмотр» показывает список и объём. Удаление начинается после подтверждения.

Модель Qwen 3B удаляется только выбранной вручную командой после остановки моста и отключения ИИ-проверки. Для включения этого модуля модель придётся снова загрузить. Уборка не удаляет Python-окружение, историю отмены, резервные копии, конфигурацию и данные задания. Встроенное обслуживание журналов самого PCBridge 2.0.0 по-прежнему выполняется при запуске оригинала.

## Сборка из исходников

В Developer PowerShell for Visual Studio с Rust MSVC:

```powershell
cargo build --locked --release --manifest-path desktop/Cargo.toml
```

Исполняемый файл появится в `desktop/target/release`. Обзор автоматизированных проверок и границы текущего переноса приведены в `migration/README.md`.

## Состав текущего этапа

- `desktop` — приложение Slint и Windows-код запуска, состояния и обслуживания хранилища.
- `storage` — инвентаризация, предпросмотр, проверяемое удаление журналов и ручное удаление модели.
- `app` — клиент локальной панели, перенос проверок Host/Origin на Rust и дифференциальные тесты на ответах Python.
- `migration` — изолированные записи Rust-Anything, Rust-сервис с временной переадресацией в Python и результаты проверок. Этот сервис служит для миграции и регрессионных тестов. Он не устанавливается в действующий PCBridge.

Сборка x64 зависит от системной библиотеки Microsoft Visual C++ Runtime (`VCRUNTIME140.dll`). Сборка ARM64 ещё не проверялась.
