## Поиск без полного снимка

`ui_find_live(window, text, role, automation_id, exact=False, limit=30, max_scan=3000, max_depth=30)` ищет в живом дереве окна и возвращает только совпадения, их refs и новый `snapshot_id`. Это отдельный поиск, а не фильтрация первых 200 узлов снимка.

Максимум обхода — 5000 узлов и глубина 50. Возвращаются `search_truncated`, `matches_truncated`, `total_matches` и `unreadable_nodes`. Неполный поиск не доказывает отсутствие элемента или уникальность совпадения. Доступен через модуль экрана; не вводит данные.

## Разница снимков

`ui_snapshot_diff(snapshot_id, max_nodes=200, max_depth=8)` повторно читает то же окно, сравнивает узлы по UIA runtime ID и возвращает `added`, `changed`, `removed`, новый `snapshot_id` и `ref_map` для сохранившихся элементов. Неизменившиеся содержимое и свойства не пересылаются повторно.

Старые refs недействительны; используйте новый ref из `ref_map` или из изменившегося элемента. `partial=true` означает, что один из снимков был неполным или отфильтрованным: `removed` тогда означает только отсутствие в новой захваченной части. Смена идентичности окна/процесса запрещает сравнение.

## Сценарии

`ui_run_steps(window, steps, timeout_seconds=30)` выполняет 1–20 шагов в одном явно выбранном окне. Общий срок — не более 45 секунд плюс ограничение времени UI-провайдера. Все параметры проверяются до первого действия. Каждый action заново ищет единственное совпадение; старые refs в сценариях не используются.

```json
{
  "window": "hwnd:12345",
  "steps": [
    {"selector": {"role": "Edit", "automation_id": "name"}, "action": "set_value", "value": "Example"},
    {"selector": {"role": "Button", "text": "Save", "exact": true}, "action": "invoke", "expect_text": "Saved"},
    {"type": "assert", "text": "Saved"}
  ]
}
```

Есть шаги `action`, `wait`, `assert`. Селектор принимает `text`, `role`, `automation_id`, `exact`. Действия совпадают с `ui_action`.

Неоднозначность, неполный поиск, модальное окно, смена целевого процесса, ошибка или неуспешная проверка значения/состояния останавливают сценарий. Результат содержит `steps`, `failed_step`, `completed_steps`, `outcome` и подсказку. Уже выполненные действия не откатываются. Если исход неизвестен, нельзя повторять весь сценарий: сначала наблюдать фактическое состояние. Требуется модуль ввода; read-only и пауза блокируют запуск.

## Диагностика

`ui_diagnose(snapshot_id="", ref="", limit=20)` возвращает последнюю ошибку, подсказку восстановления, актуальность снимка, готовность элемента, поддерживаемые действия и блокирующее модальное окно. История ограничена 50 записями. Значения ввода и содержимое сценариев в эту историю не сохраняются.
